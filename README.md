# Тихая Заводь — тренажёр по ОГЭ по алгебре

Одностраничный тренажёр для подготовки к ОГЭ по математике (алгебра, 7–9 класс).
Сделан как детектив: задачи открывают серии истории, но под сюжетом — обычная
тренировка в формате экзамена.

Работает без сборки и без интернета: весь код, стили и задачи лежат в одном файле
[`index.html`](index.html). Достаточно открыть его в браузере.

## Что внутри

| Модуль | Что тренирует |
| --- | --- |
| **Диагностика** | По одному заданию на номера ОГЭ №6–22 плюс практика №1–5. Строит карту «уверенно / базовый уровень / с основ» и советует, с чего начать. Если задание не получилось — даётся такое же, но проще. |
| **7 сюжетных серий** | Алгебра по темам учебника 7–9 классов: линейные уравнения и выражения; степени, многочлены, формулы сокращённого умножения; системы уравнений; дроби и корни; квадратные и дробные уравнения; неравенства и функции; степень с целым показателем. По 8 задач в серии, серия засчитывается с 6 верных. |
| **Практика №1–5** | Шины, участок, бумага, электросчётчик: одна ситуация и пять вопросов к ней, как на экзамене. |
| **Счёт и оценки (№6, 7, 10, 12, 14)** | Вычисления с дробями и степенями, число на координатной прямой, вероятность, расчёт по формуле, прогрессия в задаче. |
| **Геометрия №15–19** | Углы и диагонали, окружность, площади, клетчатая бумага, «верные утверждения». Чертежи строятся по числам задачи. |
| **Графики №11 и №22** | Соответствие графика и формулы, график с модулем и число общих точек с прямой. Графики рисует программа. |
| **Часть 2 (№20, 21, 23, 24, 25)** | Развёрнутые задания: решение в тетради, сверка с образцом и самооценка по критериям ФИПИ (0–2 балла). |
| **Неравенства: метод интервалов** | Отдельная тема с уроком и 8 задачами по шагам. |

В каждой тренировке — вторая попытка при ошибке, две подсказки, строка «Идея»
и подробный разбор каждого шага.

## Как устроены задачи

* Числа генерируются случайно при каждом открытии, поэтому повторное прохождение
  не повторяет условия.
* Ответ считает сама программа по тем же числам, что стоят в условии, и отдельно
  перепроверяет его другой формулой (`v`). Ошибки в ключе из-за этого не возникает.
* Чертежи (геометрия, графики, координатная прямая) строятся из тех же чисел, что и
  условие, — расхождений между чертежом и текстом нет.
* Прогресс хранится в `localStorage` браузера; результат можно скопировать текстом
  и отправить преподавателю. Псевдоним вместо имени — по желанию.

## Запуск локально

```bash
# просто открыть файл
xdg-open index.html      # macOS: open index.html

# или поднять статический сервер
python3 -m http.server 8000
# затем http://localhost:8000/
```

Публикуется через GitHub Pages из ветки `main` (файл `index.html`).

## Самопроверка

```bash
node tools/selftest.js        # 120 повторов по умолчанию
node tools/selftest.js 500    # дольше и надёжнее
```

Скрипт выполняет код страницы в Node с заглушками DOM, прогоняет все генераторы
(условия серий, практику, геометрию, графики, часть 2, диагностику) и проверяет, что
у каждой задачи ответ совпадает с собственной проверкой, нет `undefined`/`NaN`
в тексте, а у задач есть «Идея» и две подсказки. Затем проходятся все экраны до
результата. Полезно после правок генераторов: расхождение ключа и разбора видно сразу.

## Структура

```
index.html          # вся программа: разметка, стили, генераторы задач, логика экранов
tools/selftest.js   # проверка генераторов и экранов без браузера
```

Внутри `index.html`:

* `/*GEN-START*/ … /*GEN-END*/` — утилиты и задачи диагностики (`BLOCKS`);
* `SERIES` — тексты сюжетных серий, `BLOCKS[i].sgens` — их генераторы;
* `INEQ`, `PRAC`, `GEO`, `GR`, `P2`, `BASE` — остальные модули;
* `home()`, `intro()`, `pracScreen()`, `result()`, `diagScreen()`, `p2Screen()` — экраны;
* `render()` и `act()` — единая точка отрисовки и обработки действий.

## Требования

Современный браузер (нужны шаблонные строки, `localStorage`, `navigator.clipboard`).
Вёрстка рассчитана на телефон: одна колонка, крупная цифровая клавиатура, тёмная тема
по системной настройке.
